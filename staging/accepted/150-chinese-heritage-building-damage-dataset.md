## 来源概述

chinese-heritage-building-damage-dataset 是发布在 Kaggle 上的中国遗产建筑损伤图像数据集，面向建筑病害识别、文化遗产保护和计算机视觉任务。它适合用于训练或评估遗产建筑损伤检测模型。

## 收录内容与边界

该来源主要包含与中国遗产建筑损伤相关的图片及可能的标签。公开信息未必完整说明采集地点、建筑类型、损伤分类标准和标注流程，因此不宜默认其覆盖全部遗产建筑病害类型。

## 获取方式

用户可通过 Kaggle 数据集页面登录后下载文件，或使用 Kaggle API 获取。批量使用时应记录数据集版本，并检查目录结构、标签文件和样本重复情况。

## 使用与访问限制

该来源在 Kaggle 上公开可访问，但具体许可证需以 Kaggle 页面当前标注为准。图片可能涉及建筑、拍摄者或采集平台权利，正式商用或再分发前应核验授权。

## 质量与风险

该来源适合视觉模型实验。主要风险在于样本来源、拍摄条件、损伤标签和类别均衡性不明确；应用到真实文保巡检前需要更严格的专家标注和现场验证。
