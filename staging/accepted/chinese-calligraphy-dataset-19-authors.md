## 来源概述

该来源是一份开源书法字符图像数据集，由 GitHub 用户 zhuojg 维护。数据集聚焦单字图像层面的书法样本，覆盖 19 位书法家、约 13.8 万张字形图像，具有明确的作者维度标注。其核心优势在于规模大、作者维度清晰，适合做字符识别与书写者/风格判别任务，但单字切片会弱化章法与行气等整体信息。

## 收录内容与边界

- **覆盖范围**：单字图像切片的书法样本集合，按照书法家组织
- **数据规模**：约 13.8 万张字形图像，来自 19 位书法家
- **字符覆盖**：样本在不同字符上的数量可能不均衡，长尾字存在分布差异
- **内容形式**：图像文件、字符分类标签、样本元数据（以仓库 README 为准）
- **主要限制**：不覆盖作品整体、章法布局等内容；如需全幅分析需另外补充全幅数据

## 获取方式

- **仓库地址**：https://github.com/zhuojg/chinese-calligraphy-dataset
- **获取方法**：直接访问 GitHub 仓库，从 release 或仓库指引下载数据文件
- **推荐做法**：建议先抽样验证目录结构与标签映射，并固定 commit 版本以保证可复现性

## 使用与访问限制

- **访问级别**：公开可直接下载，无需身份认证或特殊权限
- **使用许可**：Apache-2.0（以仓库 LICENSE 为准）
- **适用场景**：书法字符识别基线、书写者识别与风格分类、书法教育产品开发
- **敏感性**：无个人隐私信息

## 质量与风险

- **一致性风险**：来源多样可能导致图像清晰度、背景差异，建议统一预处理管道（如归一化、去背景、对齐）
- **数据不均衡**：长尾字的样本不足，可能需要特殊处理（如重采样、度量学习等）
- **稳定性考虑**：依赖 GitHub 托管；建议在本地保存关键版本，固定 commit 或 release 版本作为参考
