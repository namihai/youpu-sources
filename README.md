`youpu-sources` 是一份面向中国文化领域开放数据集与数字资源的来源清单。

它不收录数据集文件本身，而是整理“数据在哪里、由谁发布、如何获取、使用时需要注意什么”。如果你在寻找可用于研究、教学、产品原型或文化计算实验的数据资源，可以把这里当作一个经过初步核验的入口目录。

## 收录范围

我们主要关注中国文化相关的开放数据集和数字资源，包括但不限于古籍、文物、博物馆藏品、非遗、历史地理、书画、戏曲、音乐、方言、古文字、传统图像和文化遗产等方向。

来源渠道以互联网上公开可访问的信息为主，例如：

- Hugging Face、GitHub、Kaggle 等数据或代码平台
- 高校、实验室、研究项目和研究者主页
- 博物馆、图书馆、档案馆和文化机构网站
- 论文、竞赛、基准任务和公开项目页面

清单会不定期更新。

## 收录原则

我们的目标不是“越多越好”，而是尽量保证每条记录至少是可用的。

一般来说，进入清单的来源需要满足：

- 能在公开渠道找到稳定说明或入口
- 链接在收录时可以访问
- 能判断它确实对应一个数据集、数据资源或可复用的数据入口
- 描述信息足够支撑用户判断是否值得继续查看

失效链接、无法确认来源、没有清晰访问入口或明显不可用的资源不会收录。

## 数据资源描述

每条记录都会包含来源描述和使用提示。描述可能由人工智能辅助整理，也会加入人工审阅，重点说明来源内容、获取方式、访问限制、质量风险和使用边界。

这些描述不是一次性完成的，也会随着资料补充和链接状态变化不定期更新。

## 如何使用

你可以直接浏览仓库中的 [`data/`](data/) 目录。每个 Markdown 文件对应一个数据资源来源，文件内包含 meta 信息和正文说明。

也可以使用查询网站：

[youpu.namihai.com](https://youpu.namihai.com)

如果你希望离线使用或批量处理，也可以直接 clone 这个仓库。
