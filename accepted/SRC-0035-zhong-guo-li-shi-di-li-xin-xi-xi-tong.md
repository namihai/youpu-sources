## 数据集概览

- **数据集名称**：中国历史地理信息系统（CHGIS）
- **覆盖内容**：覆盖公元前 221 年至 1911 年的历史行政区划与地名时空数据（边界/点位/层级关系等），可作为 GIS 图层与属性表使用；不同版本之间边界与地名规范可能存在差异，产品化前需固定版本与时期切片口径。
- **核心价值**：提供“带起止时间 + 层级关系 + 空间要素”的历史时空框架，适合把人物、事件、文献等外部数据挂接做联动分析；作为 AI 数据更偏底座与索引，价值在可解释的时空检索与对齐。
- **适用场景**：历史 GIS 分析与可视化 / 地名检索与时空标注 / 数字人文知识库底座 / 跨数据源空间 join（需先确认许可与版本口径）

## 数据内容说明

1. CHGIS 是一个历史地理信息数据库，包含历代中国行政单位（如省、府、州、县等）及地点的名称、时间有效期和空间位置信息。
2. 数据覆盖多个时段，可按时间序列分析行政区划的变迁，同时包含 1820 年和 1911 年间非行政主要市镇数据。
3. 数据以**空间图层 + 属性表**形式呈现（多为向量要素、坐标点与边界轮廓），可用于 GIS 软件映射与结合其他数据集（如问卷、人物、事件等）进行空间联动分析。
4. 数据总量包括数千个行政单位及数万历史地点记录，具体随着版本（如 Version 6）而扩展。
5. CHGIS 中的记录具有时间维度（开始/结束年份）、空间坐标与层级关系，可用于构建历史时空数据库与地理模型。

- **版权归属**：由 Harvard Yenching Institute 与 Fudan University 等科研机构联合开发。
- **使用许可**：公开提供免费供学术研究使用；具体许可应参考 DataVerse 页面许可声明。
- **禁止事项**：通常禁止商业再分发、未经授权的商业用途，需按照许可页说明执行（如不得二次分发未经许可的数据）。
- **合规依据**：项目官方许可与导出说明。
- **敏感性**：无个人当前数据，涉及历史地理公共信息。

## 数据质量与已知问题

- **完整性**：覆盖了绝大多数中国历史行政单位及地名；少数边缘地区可能在不同版本内存在差异。
- **一致性**：时间序列设计允许单位随时间变更属性，但不同来源地图或历史记载差异可能对边界精度造成影响。
- **时效性**：项目主要截至 2016 年发布第六版，目前不太可能频繁更新。
- **稳定性**：因开放提供，主数据及服务整体稳定；下载渠道与 API 访问稳定性视网络与平台状态。
