# 大都会艺术博物馆开放数据（The Met Open Access）

## 亮点

- 收录超过 492,000 件公共领域作品的图像，以及超过 470,000 件馆藏作品的基本数据，跨越 5,000 余年全球艺术。
- 图像与数据均以 CC0 许可开放，可免费用于商业或非商业用途。
- 提供 RESTful API（JSON）、UTF-8 编码的 CSV（MetObjects.csv）与在线收藏检索三种获取方式。
- 另提供 100 余件馆藏作品的三维模型。
- URL：https://www.metmuseum.org/hubs/open-access

## 项目概述

大都会艺术博物馆开放数据（The Met Open Access）由纽约大都会艺术博物馆（The Metropolitan Museum of Art）于 2017 年 2 月推出，将馆藏中公共领域作品的图像，以及全部入藏作品的基础数据，以 CC0（Creative Commons Zero）方式开放，供任何人免费、不受限制地下载、分享与再创作。馆藏跨越 5,000 余年、来自全球的艺术，中国艺术（青铜器、玉器、陶瓷、书画等）是其中重要的收藏门类；作为面向全球艺术的总馆藏开放数据，它并非单一中国主题，但可支持中国文物与艺术史研究。

## 收录内容与规模

数据集包含两部分：一是超过 470,000 件馆藏作品的元数据记录，覆盖全部入藏作品，其中也含仍在版权保护期内作品的身份信息；二是超过 492,000 件公共领域作品的高分辨率图像（JPEG），可通过在线收藏与 API 获取。图像不包含在 CSV 数据集中，公共领域作品在博物馆网站以 CC0（OA）图标标识。此外还提供 100 余件馆藏作品的三维模型，可在网页中旋转、缩放查看。

## 获取方式

数据有三种获取途径：通过 The Met 的 RESTful API（JSON 格式，可访问全部开放数据及对应的公共领域高分辨率图像，https://metmuseum.github.io/）；从 GitHub 仓库下载 UTF-8 编码的 CSV 文件 MetObjects.csv（以 Git LFS 存储，https://github.com/metmuseum/openaccess）；以及在在线收藏中按开放访问筛选浏览并下载。数据持续更新，官方建议定期同步以获取最新版本。

## 访问与使用条件

图像与数据均按 CC0 放弃版权及相关权利，可用于任何媒介、商业或非商业用途而无需许可或付费。官方使用准则建议在研究与发表中署名致谢，并不得曲解数据集或其来源、不得冒用博物馆商标或暗示博物馆背书；对数据集的任何转换或修改应明确标注。
