## 来源概述

该来源是以 GitHub 组织形式分发的大规模传统汉文文献语料库。Kanripo 社区维护了多个文献子库，内容涵盖传统古籍与汉文文献。所有内容采用统一的 CC BY-SA 4.0 许可，支持版本控制与本地镜像，适合学术研究与 AI 模型训练。

## 收录内容与边界

- **覆盖范围**：传统汉文文献集合，由多个子库组织，涵盖各类古籍文献
- **组织方式**：通过 GitHub 组织分发，按书/卷/篇等结构组织，具体覆盖范围以各子库说明为准
- **规模**：未明确披露，建议以仓库统计脚本生成可复现指标
- **主要限制**：子库间来源、目录结构与文本规范可能不一致，使用前需核验具体子库说明
- **版本控制**：可通过 git 追踪版本，建议固定 commit hash 以保证可复现性

## 获取方式

- **组织主页**：https://github.com/kanripo
- **获取方法**：直接 git clone 相应子库或访问仓库页面获取文件
- **推荐做法**：记录 commit hash 便于版本固化；对外发布衍生数据前需确认许可兼容性
- **本地镜像**：建议建立本地镜像以降低外部依赖风险

## 使用与访问限制

- **访问级别**：公开可直接获取
- **使用许可**：CC BY-SA 4.0（所有内容遵守该许可）
- **许可要求**：对外发布衍生数据需署名与同方式共享（CC BY-SA 合规义务）
- **适用场景**：学术研究、NLP 模型训练、古文检索与向量化、数字人文分析
- **商业用途**：需明确确认各子库声明是否允许商业用途
- **敏感性**：一般不涉及个人信息

## 质量与风险

- **一致性风险**：子库间编码、标点、段落切分、异体字处理等口径可能不一致，需统一预处理
- **覆盖完整性**：虽覆盖范围广，但不保证每一类文献齐全
- **时效性**：项目不定期更新，建议关注仓库动态
- **稳定性**：依赖 GitHub 与项目维护，建议建立本地镜像以降低风险
- **合规成本**：对外发布衍生成果时需严格遵守 CC BY-SA 署名与同方式共享义务
