## 数据集概览

- **数据集名称**：CBETA XML P5 语料库
- **覆盖内容**：以 TEI P5 XML 形式发布的汉文佛教典籍文本，结构化标记较丰富，适合做检索、引用与数字人文分析。
- **核心价值**：相比纯文本，TEI 结构能保留章节层次、注释等信息，方便做更精细的文本计算与可追溯引用；但对外产品/商用前需要优先核清版权与“例外条款”，避免后期合规返工。
- **适用场景**：佛教文献研究、结构化检索与对齐、古文语料处理、文本标注与知识抽取；更推荐用于研究与内部分析场景，若要对外发布衍生数据/服务需先完成许可审查与署名/分享义务设计。

## 数据内容说明

1. 数据以 TEI P5 XML 形式组织，包含文本与结构化标记。
2. 适合用 XML 解析管线做清洗、抽取与索引。
3. 不同典籍的版权/许可可能存在差异，需要按项目声明核对。
