## 来源概述
Open-Oracle 是甲骨文识别、释读和跨模态理解研究的项目汇总仓库。页面列出 OBSD、EVOBC、oracle bone script recognition and decipherment 等多个相关项目，并提供部分代码、论文和数据下载入口。

## 收录内容与边界
该条目更像“项目集合入口”，不是单一数据集。它可用于定位甲骨文数据、模型和论文资源；如果后续要正式沉淀为高质量 accepted 记录，建议进一步拆分到具体数据集条目，例如 EVOBC 或 Scientific Data 2024 对应的数据下载页。

## 获取方式
GitHub 页面公开可访问；具体数据需要进入页面中标注的 Dataset 或 Download Dataset 链接。

## 使用与访问限制
仓库入口公开；不同子项目、数据下载页和论文资源可能有不同许可与引用要求，应按具体子项目分别核对。

## 质量与风险
作为汇总入口有助于发现资源，但粒度偏粗。若 accepted 只收录“稳定数据集来源”，该条目应在正式提交前拆成具体数据集来源，或降级为线索。
