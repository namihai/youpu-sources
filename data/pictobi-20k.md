# 象形甲骨字与现实物体视觉对应数据集与评测基准（PictOBI-20k）
## 亮点
- 评估多模态大模型对甲骨象形关系的视觉理解能力
- 图像总量：20,008张
- 核心评测题：15,175道四选一题
- 字符类别：80类
- 论文状态：ICASSP 2026
- 数据大小：865MB
- 许可协议：MIT
- URL：https://huggingface.co/datasets/Fossilman/PictOBI-20k/tree/main
## 数据组成
PictOBI-20k名称中的“20k”由两部分图像共同构成：
| 数据组成 | 数量 |
|---|---:|
| 甲骨文字形图像 | 15,175 |
| 现实物体图像 | 4,833 |
| 图像合计 | 20,008 |
| 多项选择题 | 15,175 |
| 人工参考点标注图像对 | 240 |
| 象形甲骨字类别 | 80 |
| Hugging Face压缩包 | 约865 MB |

因此，20k代表甲骨字图像与现实物体图像的合计规模。核心评测样本量是15,175道选择题，每道题以一张甲骨字图像为查询对象。
## 类别构成
数据集依据裘锡圭有关象形文字的分类研究，选择80类代表性甲骨字：
* 普通象形类别：70类；
* 复杂象形类别：10类。

复杂类别通常包含组合性图形，需要结合多个构形元素或语境理解，难度高于直接描绘单一物体的象形字。这种类别设计有明确的文字学依据，但80类仍然只覆盖甲骨文字中的象形部分，不能代表完整的甲骨文字系统，也不覆盖全部会意字、形声字和未释字。
## 甲骨文图像来源
PictOBI-20k整合了三个古文字网站和五个既有甲骨文数据集。论文公布的数量如下：
| 来源 | 图像数量 |
|---|---:|
| 殷契文渊 | 761 |
| 小学堂 | 1,731 |
| 国学大师 | 35 |
| Oracle-241 | 1,994 |
| Oracle-50K | 5,635 |
| HUST-OBS | 4,539 |
| OBI125 | 410 |
| OBIdatasetIJDH | 70 |
| 合计 | 15,175 |

数据同时包含：
* 真实拓片裁剪字符；
* 摹写或手摹字符；
* 不同分辨率和背景条件下的甲骨字图像。
Oracle-50K和HUST-OBS合计占据较大比例，数据整体分布会明显受到这两个上游数据集的影响。

## 现实物体图像来源
4,833张现实物体图像来自：
* Freepik；
* Pexels；
* Pinterest；
* 中央研究院青铜器资料库。

论文表示这些图片按照适当的CC BY条件收集。不过，Pinterest主要承担图片聚合和链接传播功能，图片原始权利通常取决于最初发布者。将整个物体图片集合统一理解为CC BY可能过于宽泛，正式使用时仍应核查单张图片来源。
## 任务设计
核心任务采用四选一视觉问答：
```
输入
├── 一张象形甲骨字图像
├── 问题：该甲骨字对应哪个现实物体？
└── 四个现实物体候选图像

输出
└── 正确选项
```
干扰选项从其他类别抽取。为了降低选项位置偏差，作者会轮换或随机改变正确答案所在位置。这种设计能够量化评估，但模型可能利用候选图片类别、语言提示或选项分布完成题目。论文因此另外设计了人工参考点标注，用于检测模型的视觉关注区域是否与人类专家一致。
## 数据结构
下载并解压后，README说明数据包含两个JSON文件和三个图像目录：
```
PictOBI-20k/
├── quiz_data.json
├── quiz_reference_point.json
├── OBC_image/
├── object_image/
└── reference_point_quiz/
```
其中：
* `quiz_data.json`：多项选择题数据；
* `quiz_reference_point.json`：参考点与视觉一致性评测数据；
* `OBC_image/`：甲骨字图像；
* `object_image/`：现实物体图像；
* `reference_point_quiz/`：参考点实验所需图像。

README没有进一步解释JSON的完整字段定义、唯一标识符规则、类别编码体系及上游来源字段是否保留。若需要长期维护或转换为统一数据格式，仍需检查实际JSON文件。
