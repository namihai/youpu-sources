# 佛学人名规范资料库（DDBC Person Authority）

## 亮点

- 由法鼓文理学院（DILA）建置的佛学人名规范资料库，是「佛学规范资料库」项目的人名部分，现收录人名 49,433 条、人名群组 110 组。
- 以 XML/TEI 与 RDF 格式开放下载，提供规范编号（A 编号）便于跨项目检索与同名消歧。
- 许可协议：CC BY-SA 3.0（Unported）。
- 同时托管于 GitHub 公开仓库，并配套 Web Services API。
- URL：https://authority.dila.edu.tw/person/

## 数据内容

DDBC 人名规范资料库（Buddhist Studies Person Authority Databases）是法鼓文理学院图书资讯馆数位典藏组「佛学规范资料库」项目的人名部分，旨在整合各佛学专案中的人物资料、建立历史对照，并通过对佛典人名进行规范与消歧，支持跨项目检索与地理空间参照。资料库收录佛典相关人名规范资料，现共 49,433 条人名、110 组人名群组，每条赋予规范编号（A 编号），并提供被参考次数排名、别名、最近新增/修改等检索功能。资料以 XML/TEI 与 RDF 格式开放，另提供 Web Services API。

## 获取与许可

资料以 CC BY-SA 3.0（Unported）发布，可从网站下载区直接下载（人名资料 XML/TEI 当前版 2026 年 9 月，约 8.42 MB；另有 2020 年 12 月 RDF 版约 58.57 MB），并同步托管于 GitHub 仓库 DILA-edu/Authority-Databases。
