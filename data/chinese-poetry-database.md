# 中文诗歌古典文集数据库
## 要点
- 包含 5.5 万首唐诗、26 万首宋诗、2.1 万首宋词和其他古典文集。诗人包括唐宋两朝近 1.4 万古诗人，和两宋时期 1.5 千古词人。
- 除了诗歌，还包含了《诗经》《楚辞》《论语》、四书五经、蒙学、《幽梦影》、元曲、五代诗词、纳兰性德诗集、曹操诗集等。
- 数据来源于互联网。
- 数据大小：91.2MB
- 数据格式：JSON
- 许可协议：MIT
- URL：https://github.com/chinese-poetry/chinese-poetry
## 数据内容
主要内容包括：
- 唐诗、宋诗及作者信息；
- 宋词、词牌和作者介绍；
- 五代《花间集》《南唐二主词》；
- 《诗经》《楚辞》；
- 《论语》及部分四书五经；
- 元曲、蒙学读物、《幽梦影》；
- 纳兰性德、曹操等个人诗集；
- 部分平仄、排名、标签和分析辅助数据。
《诗经》数据示例包含 `title`、`chapter`、`section`、`content`，能够表达篇名、国风/雅颂层级及正文段落。
另外需要注意，四书五经目录页面当前展示的文件主要包括《大学》《中庸》《孟子》等，并且说明采用繁体中文、按章节拆分。目录名称所暗示的覆盖范围可能大于实际页面可见内容，使用时需要逐项核实。
## 数据结构
本数据集采用“文集目录—分片文件—记录对象”的组织方式。典型诗词字段包括：
```author      作者
title       诗题
rhythmic    词牌名
paragraphs  正文分段
strains     平仄或韵律信息
prologue    小序、题记
tags        标签
```
项目贡献规范要求使用有序 JSON 和规范字段名，但不同子数据集仍有自己的结构。例如：
- 诗、词正文通常使用 paragraphs；
- 《诗经》使用 content；
- 宋词使用 rhythmic 表示词牌；
- 作者资料可能保存在独立的 author.*.json；
- 宋词目录还提供 ci.db，应当是便于查询的数据库版本；
- 大型语料按每1,000条左右拆分；
- 简体、繁体数据并存。
这些差异意味着整个仓库还没有形成完全统一的全局 Schema。构建统一数据库时，需要增加字段映射、繁简标记、文体类型和来源集合等标准化层。
