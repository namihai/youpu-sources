# 中国书法字符标注数据集（MCCD）
## 亮点
- 华南理工大学深度学习与视觉计算实验室发布，并被ICDAR 2025接收。
- 书法单字图像数据集，标注维度包括汉字类别、书体、历史朝代、书法家。
- 共计收录329715张书法单字图像，覆盖7765个汉字类别。
- 数据大小：22.11GB
- 数据格式：PNG/Imdb
- 许可协议：CC BY-NC-ND 4.0
- URL：https://github.com/SCUT-DLVCLab/MCCD
## 数据内容
### 1. 汉字类别
全集包含7,765个汉字类别，每个汉字至少有8张图像。论文统计约48%的汉字类别拥有20张以上图像。
该类别规模高于常见简体中文字符集，预计包含一定数量的繁体字、异体字和历史字形。不过 README 没有公布完整字符表，也未说明字符编码标准是否对应 Unicode、GB18030或自定义索引。
### 2. 十种书体
书体子集包含：
* 甲骨文
* 金文
* 篆书
* 隶书
* 草书
* 行书
* 楷书
* 木牍文字
* 印章文字
* 石刻／拓印类文字
前五种常见书体之外，数据集还加入甲骨、金文、木牍、印章和石刻等历史书写形态。每个书体类别至少包含一万张图像。
### 3. 十五个历史时期
朝代子集覆盖从商代至近现代的15个历史时期。部分时间接近、书体变化较小的朝代被合并，以减少类别碎片化。
每个时期至少有2,000张图像，其中9个时期超过一万张。README 没有直接列出15个时期的完整映射表，具体标签仍需查看下载后的类别文件。
### 4. 书法家
书法家子集包含142位具有代表性的书法家：
* 每位书法家至少有100张图像；
* 36位书法家拥有超过1,000张；
* 对样本量差异过大的类别进行了筛选；
* 目标是减少严重类别失衡对书法家识别实验的影响。
## 数据结构
仓库主要包含：
```
MCCD/
├── application-form/
│   ├── Application-Form-for-Using-MCCD.docx
│   └── Legal-Commitment.docx
├── data_loader/
│   ├── lmdb_dataset.py
│   ├── 2task_MTL_lmdb_dataset.py
│   └── 4task_MTL_lmdb_dataset.py
├── picture/
└── README.md
```
完整图像数据没有存放在 GitHub 仓库中，需要通过百度网盘或 OneDrive 下载，并采用审核制访问。具体流程如下：
* 下载并填写申请表；
* 签署法律承诺书；
* 通过邮件提交给项目方；
* 附上申请者或团队近六年的1～2篇相关论文；
* 研究方向需要与OCR、书写者识别、书写分析、文档图像处理等领域相关；
* 项目方审核通过后提供压缩包解压密码。
