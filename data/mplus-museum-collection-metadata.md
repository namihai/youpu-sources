# M+ 博物馆藏品元数据数据集
## 亮点
- 香港M+博物馆公开的馆藏元数据仓库，覆盖二十、二十一世纪视觉文化，主要包括：设计与建筑、视觉艺术、流动影像、M+希克收藏、M+馆藏档案。
- 主表达到13,412 件馆藏对象，规模可观。
- 数据大小：18.8MB
- 许可协议：CC0 1.0
- URL：https://github.com/mplusmuseum/collection-data
## 数据内容
1. 馆藏对象信息
`objects.csv` 包含：
    * 馆藏 ID、藏品编号
    * 领域与类别
    * 档案层级
    * 英文及繁体中文标题
    * 展示年代、起止年代
    * 材质与媒介
    * 尺寸及宽、高、深
    * 来源和入藏说明
    * 创作者及其角色
    * 图像内容描述
    * 主要颜色及多个颜色特征字段

2. 创作者与机构信息
`constituents.csv`是独立的规范化实体表，字段包括：
    * 姓名及繁体中文姓名
    * 排序名称
    * 个人或机构类型
    * 在作品中的角色
    * 中英文简介
    * 性别
    * 生卒或成立、结束年代
    * 国籍及繁体中文国籍

3. 希克收藏拓展信息
希克收藏文件在通用馆藏字段之外增加了艺术家团体与艺术运动相关字段，包括：
    * 团体或运动名称
    * 中英文描述
    * 时间线
    * 起止年代
    * 展示年代
    * 公开访问状态
## 数据结构
仓库同时提供 CSV 和 JSON 两种形式：
- CSV 适合表格分析、数据库导入和批量统计。
- JSON 分别存放于对象、希克收藏和创作者目录，适合程序处理或接口开发。
- 文本编码为 UTF-8。
- 大量字段具有英文和繁体中文两个版本，中文字段通常以 TC 结尾。
需要注意，CSV 中部分字段保存为序列化列表，例如领域、创作者和角色可能呈现为：
```
["Design and Architecture"]
```
因此，读取 CSV 后还需要对这些单元格进行第二次解析，不能全部当作普通文本字段处理。
