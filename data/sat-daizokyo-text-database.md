# SAT 大正藏文本数据库（SAT Daizōkyō Text Database）

## 亮点

- 由東京大学 SAT 大藏經文本数据库研究会建置，获大藏出版株式会社（《大正新脩大藏經》原出版社）完全授权，1998 年上线。
- 提供《大正新脩大藏經》85 卷全文在线检索，涵盖阿含、般若、法華、華嚴、律、论、諸宗、史傳等全部部类。
- 支持全文检索（KWIC 上下文显示）、按经典/卷/部/作者译者检索，并提供原书页图像缩放对照。
- 与电子佛教辞典（DDB）、BDK 英译平行语料、INBUDS/SARDS/CiNii 书志库及文字编码数据库联动；经 SAT 提案，逾 2800 个未编码汉字纳入 Unicode 10.0、329 个纳入 Unicode 13.0。
- URL：https://21dzk.l.u-tokyo.ac.jp/SAT/index_en.html

## 项目概述

SAT 大正藏文本数据库（SAT Daizōkyō Text Database）由東京大学 SAT 大藏經文本数据库研究会（SAT Daizōkyō Text Database Committee，隶属東京大学人文社会系研究科印度哲学佛教学研究室）建置，1998 年 3 月 17 日上线，向公众提供《大正新脩大藏經》85 卷的全文，是国际佛教学研究广泛使用的基础性数字典藏。该数据经大正新脩大藏經原出版社大藏出版株式会社的完全授权开放使用。

文本数据库历经多个版本演进：SAT 2007、SAT 2012、SAT 2015，以及 2018 年发布的 SAT DB 2018。其中 SAT 2012 以四项原则为纲——确保文本来源可靠性、构建研究者可持续协作系统、实现研究项目间协作同时尊重各自独立、提供集成化接口——并首次提供原书页图像的可缩放对照，使读者能逐行核对原文。

## 内容与收录范围

数据库收录《大正新脩大藏經》85 卷全文，按大正藏原有分类组织为树状目录，涵盖阿含部、本縁部、般若部、法華部・華嚴部、寶積部・涅槃部、大集部、經集部、密教部、律部、釋經論部、毘曇部、中觀部・瑜伽部、論集部、經疏部、律疏部・論疏部、諸宗部、史傳部、事彙部・外教部・目録部，以及续编的續經疏部、續律疏部・續論疏部、續諸宗部、悉曇部、古逸部・疑似部，另附浄土宗全書（正、続）。逐经均可展开查看经典名、作者与译者，并可点击进入全文。

除文本主体外，SAT 还发布了一系列关联资源：与法兰西铭文与美文学院合作的 Digital 法寶義林（Hôbôgirin）、符合 IIIF 规范的 SAT IIIF 图像服务器、東京大学所藏梵文写本数据库，以及含 20,800 条图标注记的 SAT 大正藏图像数据库（Taishōzō Image DB）。

## 检索与功能

数据库提供全文检索，检索结果可按 KWIC（Keyword in Context）上下文、按经典、按伪段落三种方式呈现，并支持对经典、卷、部及作者/译者名的逐级筛选与 AND/OR 组合。检索窗口通过英文输入可联想中文候选词。在非模糊模式下可区分 CJK 兼容汉字。正文旁的原书页图像支持拖动浏览与缩放。

平台与多个外部资源联动：选中文本可即时查询电子佛教辞典（Digital Dictionary of Buddhism，DDB）与 BDK-SAT 平行语料（大正藏与 BDK 英译的逐句对译）；书志工具可检索 INBUDS、SARDS、CiNii 等文献库；文字信息功能可显示所选字符的 Unicode 码点并链接至相关文字编码数据库（如 Chise、Unihan）。
