# 汉字历史演变数据集（GBEDOBC）
## 亮点
- 将字形图像转换成节点—边图结构。
- 同时保留原始字形图像、邻接矩阵和图嵌入向量。
- 覆盖从甲骨文到楷书的五个历史阶段。
- 数据大小：20.7MB
- 许可协议：CC BY-NC-ND 4.0
- URL：https://github.com/BrisksHan/GBEDOBC
## 数据规模
| 项目 | 信息 |
|---|---:|

| 每组字形 | 5个 |

| 历史阶段 | 5个 |
| 图结构数量 | 与3,780张图像对应 |
| 图像尺寸 | 105×105像素 |
| 图像模式 | 灰度图 |
| 图类型 | 无向、无权图 |
| 公开压缩包 | 20.7 MB，7z格式 |
| 图嵌入维度 | 12维 |

## 数据来源与清洗
原始数据来自较早发布的汉字演变数据，共972组、4,860张图片，主要来源于国学大师网站和顾延龙等相关字源资料所代表的《汉字源流字典》。研究团队发现原始数据混入行书、草书等超出目标五阶段范围的字形，于是人工筛除1,080张图像，最终保留756组、3,780张图像。

图像预处理包括：
* 加权平均法灰度化；
* 双线性插值；
* 尺寸统一到105×105像素；
* 人工筛除不属于五个目标阶段的样本。

这套数据直接继承的是2022年汉字演变研究中的972组数据，并没有以EVOBC（有谱已收录）的229,170张图像作为底层来源。
