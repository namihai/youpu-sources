# 青铜铭文修复与年代测定数据集（BIRD）
## 亮点
- 面向中国早期青铜器铭文的文本复原与年代判定。
- 收录先秦传世文献，用于领域自适应预训练。
- 数据大小：8.1MB
- 许可协议：MIT
- URL：https://github.com/wjhuah/BIRD
## 数据内容
### 1. 领域预训练语料
`data`/`dapt.txt` 收录先秦传世文献，用于领域自适应预训练。关联模型卡说明其约有200万词元，来源包括：
* 《论语》
* 《孟子》
* 《左传》
* 《墨子》
* 《管子》
* 其他先秦文献
这部分用于帮助模型学习与金文时代接近的古汉语表达，并不属于核心出土铭文数据。
### 2. 铭文复原数据
复原数据位于：
```
data/tapt_train.txt
data/tapt_test.txt
```
结构非常简单，每行是一段铭文纯文本，例如：
```
唯十又九年，四月既朢辛卯，王在周康卲宮，各于大室，即位……
```
主要特点：
* 保留繁体字和古文字转写字符；
* 保留Unicode扩展区汉字；
* 不可释读字使用带编号的 `[UNK-xxxxx-x]` 占位符；
* 没有独立的器物编号、朝代、时期或出处字段；
* 训练集与测试集约按9:1组织。
由于文件只保存文本，用户很难直接把每条复原文本关联回具体青铜器、拓片、著录页或博物馆藏品。
### 3. 断代数据
`dating.csv` 有808行，其中一行为表头，即 807条数据记录。字段为：
```
id,dynasty,period,text
```
| 字段 | 含义 |
|---|---|
| `id` | 铭文或数据记录编号 |
| `dynasty` | 朝代标签 |
| `period` | 早期、中期、晚期 |
| `text` | 铭文转写文本 |

朝代分布如下：
| 朝代 | 记录数 | 占比 |
|---|---:|---:|
| 西周 | 526 | 65.2% |
| 春秋 | 185 | 22.9% |
| 战国 | 70 | 8.7% |
| 殷 | 26 | 3.2% |

时期标签分布如下：
| 时期 | 记录数 |
|---|---:|
| 晚期 | 342 |
| 早期 | 242 |
| 中期 | 176 |
| 空缺 | 47 |
### 4. 异字体关系网络
Glyph Net 位于三个 `.edge` 文件：
| 文件 | 原始行数 | 唯一关系数 | 涉及字形数 |
|---|---:|---:|---:|
| `Yin.edge` | 67 | 53 | 102 |
| `Western_Zhou.edge` | 638 | 638 | 943 |
| `SpringAutumn_WarringStates.edge` | 387 | 387 | 637 |
| 合计 | 1,092 | 1,078 | 各时期之间可能重叠 |

每行表示一个古文字字形与通行字或基本字之间的关系，例如：
```
丌 其
𠂤 師
```
项目利用这些关系构建异体字家族，使模型可以同时进行：
* 精确字符补全；
* 同一异体字家族内的宽松补全；
* 新字形嵌入对齐；
* 跨时期字形演化研究。
`Yin.edge`中存在14行重复关系，因此论文所称的1,078对对应去重后的关系总量。
## 数据结构
仓库主要结构位：
```
BIRD/
├── data/
│   ├── dapt.txt
│   ├── tapt_train.txt
│   ├── tapt_test.txt
│   ├── dating.csv
│   ├── Yin.edge
│   ├── Western_Zhou.edge
│   ├── SpringAutumn_WarringStates.edge
│   └── Net_json_format/
├── UNK/
├── figure/
├── results/
├── main.py
├── requirements.txt
├── LICENSE
└── README.md
```
数据模态以结构化和半结构化文本为主：
* TXT：预训练及复原语料
* CSV：朝代与时期标注
* EDGE：异体字关系
* JSON：异体字网络的另一种表示
* UNK资源：未识别字相关材料
* Python：训练、评估和错误分析流程
核心仓库没有形成青铜器照片、拓片或单字图像数据集。这导致它更适合古文字NLP和铭文文本研究。
