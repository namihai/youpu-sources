# 十九位书法家单字图像数据集
## 亮点
- 共收集 138,499 张中国书法单字图像。
- 覆盖 19 位书法家的书写样本，字符总类数为 7,328 个。
- 图像来自互联网整理，字符类别分布不均衡，多数字符类别少于 40 张图像。
- 图像尺寸差异较大，使用前通常需要做尺寸归一化、裁切、填充或重采样处理。
- 数据提供两个版本：按“字符”分文件夹的 JPG 版本，以及按“书法家”分组的 GIF 版本。
- JPG 字符分类版本适合字符识别；GIF 书法家分类版本适合书法家识别和风格分类。
- 仓库提供 TensorFlow 2 和 PyTorch 两套数据加载示例代码。
- 数据大小：JPG 字符分类版本 747MB；GIF 书法家分类版本 289MB。
- 许可协议：Apache-2.0。
- URL：https://github.com/zhuojg/chinese-calligraphy-dataset

## 数据内容
这份数据集把中国书法作品拆解为单字图像，并围绕“字符类别”和“书法家来源”提供两种组织方式。数据总量为 138,499 张，覆盖 7,328 个不同字符，由 19 位书法家的互联网图像整理而来。它适合用来研究书法图像中的两个基本问题：一是“这张书法单字写的是哪个汉字”，二是“这张字更接近哪位书法家的风格”。

第一套数据按字符组织，文件格式为 JPG。每个字符对应一个文件夹，例如“一”“丁”“七”“万”等，适合训练字符分类或书法 OCR 模型。仓库说明中给出的目录结构包括 data/chinese-calligraphy-dataset/ 和 label_character.csv，后者用于建立字符标签映射。

第二套数据按书法家组织，文件格式为 GIF。它更适合处理风格识别任务，例如判断图像来自哪位书法家，或比较不同书法家在笔画粗细、结构重心、线条转折、字形开合和整体气息上的差异。

## 文件组织与使用方式
仓库 README 建议将下载后的数据解压到项目同级的 data 文件夹中。典型结构为：data 文件夹下包含 chinese-calligraphy-dataset 文件夹和 label_character.csv；其中 chinese-calligraphy-dataset 下面按字符分文件夹，例如 ㄚ、一、丁、七、万等。

仓库提供了两个数据加载脚本：dataset-tf.py 用于 TensorFlow 2，README 示例中使用的是 TensorFlow 2.3；dataset-pytorch.py 用于 PyTorch，可配合 torch.utils.data.DataLoader 批量读取图像和标签。

README 中还提供了简单的可视化示例：加载一个 batch 后，用 Matplotlib 显示图像，并根据 label_character.csv 把标签转回对应汉字。这说明该仓库不只是给出下载链接，也提供了基本的实验入口，适合快速验证数据是否能被模型正确读取。

## 数据特点
这份数据的优势是规模较大、字符覆盖面广，并且同时支持“按字分类”和“按书法家分类”两类任务。7,328 个字符类别使它比普通手写汉字识别数据更接近书法场景中的长尾分布：常见字样本较多，低频字样本较少，这对模型的泛化能力是一个现实挑战。

README 特别指出，多数字符类别少于 40 张图像，且图像尺寸变化明显。因此，它并不是一个规整、均衡、统一尺寸的标准视觉分类数据集。实际使用时通常需要先做预处理，包括统一图像尺寸、灰度或 RGB 处理、背景规范化、类别筛选、样本均衡，以及对低频字符进行合并或单独评估。

## 适用场景
这份数据适合用于书法字符识别、书法家分类、书法风格表征、图像检索、生成式书法模型、少样本学习和长尾分类实验。由于仓库提供了 TensorFlow 和 PyTorch 的读取示例，它也适合教学和快速原型实验。

如果研究目标是书法史、碑帖版本、作品出处、书体流变或艺术史解释，这份数据还不够完整。它主要提供图像和标签，没有系统标注作品名称、创作年代、书体类别、碑帖来源、原始图像出处和版本信息。用于学术书法研究时，需要结合更权威的书法文献、馆藏图像或碑帖数据库。
